# Conformance corpus

Small, committed input files for the T1–T9 certification tests, organised as
`corpus/<kicad-major.minor>/<name>/…` by the KiCad format epoch (or, for reports, the
kicad-cli version) that produced them. Everything here is either hand-written or generated by
the research spikes in `spikes/` (see `spikes/README.md`); nothing is copied from KiCad's own
demo projects. Those are read at test time from `<install>/share/kicad/demos` through
`demos.collect_demo_files(share_dir)` and are never committed.

Total size is ~0.5 MB. Line endings are kept exactly as the producing tool wrote them (KiCad on
Windows writes CRLF, the generators write LF); T1 reads them byte for byte.

### `10.0/handwritten`

* `tiny.kicad_sym` — a one-symbol library (`R`, the body copied out of `ldo_test.kicad_sch`'s
  embedded `Device:R`) emitted by `build()`. `kicad-cli 10 sym upgrade --force` re-saves it with
  **only** the `generator` name (and CRLF) different, which is the evidence that the formatter
  reproduces KiCad's Prettify output.
* `R_0603_min.kicad_mod` — minimal two-pad footprint emitted by `build()`; `fp upgrade` loads it
  (KiCad adds uuids, the Datasheet/Description properties and `embedded_fonts` on re-save).
* `scope.kicad_dru` — a rules file with several top-level expressions and a `#` comment line
  (the syntax mirrors the shipped `demos/vme-wren/vme-wren.kicad_dru`). kicad-cli DRC runs with it
  next to `10.0/headless_board/scope.kicad_pcb`, but note kicad-cli does not surface rule-file
  parse errors, so it is validated by construction only.
* `sym-lib-table`, `fp-lib-table` — project-local tables in the 10.0 `(version 7)` shape.
* `escapes.kicad_sch` — `mini.kicad_sch` with a Value of `A\tB\\tC\"E\nF\{G\x41\101`; kicad-cli
  10 exports it as `A<TAB>B\tC"E<LF>F\{GAA`, which fixes the escape rules in `cst.unquote`.
* `comment_line.kicad_sch` — `mini.kicad_sch` with a `# comment` line; loads on kicad-cli 10
  (a comment *after* a token on the same line is rejected, so the CST only recognises line-start
  comments).

All kicad-cli runs that produced or validated these files used a throw-away
`KICAD_CONFIG_HOME`; `%APPDATA%\kicad` was hashed before and after and never changed.
